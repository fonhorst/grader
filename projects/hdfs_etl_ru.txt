## Задание: Реализация ETL пайплайна с использованием HDFS

### Описание задания

В рамках этого задания вам необходимо разработать простой ETL пайплайн, который взаимодействует с Hadoop Distributed File System (HDFS). Пайплайн должен:

1. Обнаруживать появление новых файлов в заданной директории HDFS, куда данные записываются внешним процессом.
2. Чтение обнаруженных новых файлов.
3. Выполнять заданную обработку данных.
4. Записывать обработанные данные в другую директорию на HDFS.

### Данные

Файлы содержат информацию о транзакциях в формате CSV. Пример структуры файла:

| transaction_id | user_id | amount  | currency | timestamp           | status  |
|----------------|---------|---------|----------|---------------------|---------|
| 1              | 101     | 250.00  | USD      | 2023-12-20 10:00:00 | success |
| 2              | 102     | 450.50  | EUR      | 2023-12-20 10:05:00 | failed  |
| 3              | 103     | 100.00  | USD      | 2023-12-20 10:10:00 | success |

- `transaction_id` — уникальный идентификатор транзакции.
- `user_id` — идентификатор пользователя.
- `amount` — сумма транзакции.
- `currency` — валюта транзакции.
- `timestamp` — время выполнения транзакции.
- `status` — статус транзакции (`success` или `failed`).

### Требования к обработке данных

1. Фильтровать только успешные транзакции (`status = 'success'`).
2. Конвертировать суммы всех транзакций в одну валюту (USD) по заданным курсам:
   - 1 EUR = 1.1 USD
   - 1 USD = 1 USD
3. Агрегировать данные по дате (формат `YYYY-MM-DD`), считая:
   - Общую сумму транзакций.
   - Количество транзакций.
   - Среднюю сумму транзакции.
4. Сохранить обработанные данные в следующей структуре:

| date       | total_amount | transaction_count | average_amount |
|------------|--------------|-------------------|----------------|
| 2023-12-20 | 350.00       | 2                 | 175.00         |

### Требования к реализации

1. **Обнаружение изменений:**
   - Программа должна периодически проверять целевую директорию на HDFS на наличие новых файлов.
   - Обнаружение должно быть автоматическим (например, с использованием интервалов проверки).

2. **Обработка данных:**
   - Прочитать содержимое обнаруженных файлов.
   - Выполнить указанную обработку данных.

3. **Запись данных:**
   - Все обработанные данные должны быть записаны в HDFS с использованием структуры `<основная директория>/<текущая дата>/aggregated_data.csv`.

4. **Непрерывность:**
   - Код должен работать в течение определенного периода времени (например, 30 минут), чтобы продемонстрировать способность обрабатывать несколько новых файлов, появляющихся в процессе выполнения.

5. **Мониторинг и логирование:**
   - Добавьте логирование в свою программу для записи следующих событий:
     - Обнаружение нового файла.
     - Успешное чтение файла.
     - Успешное преобразование данных.
     - Успешная запись данных в HDFS.

### Технические требования

- Используйте Python (рекомендуется использовать библиотеки `pydoop` или `hdfs` для работы с HDFS).
- Программа должна быть контейнеризирована с использованием Docker.
- Развертывание пайплайна должно быть реализовано с использованием Kubernetes (например, StatefulSet/Deployment).
- Предоставьте тестовые данные для проверки вашей реализации (например, несколько текстовых файлов с разными наборами данных).
- Предоставьте сценарии автоматического тестирования (например, с использованием `pytest`).
- Ваша программа должна быть отказоустойчивой к следующим событиям:
  - Прерывание процесса записи данных.
  - Недоступность HDFS на короткое время.

### Критерии оценки

- Корректность реализации ETL пайплайна.
- Логирование всех ключевых событий.
- Корректность обработки нескольких файлов в течение времени работы программы.
- Соответствие требованиям контейнеризации и развертывания.
- Качество кода (структура, комментарии, использование библиотек).
- Дополнительные баллы за использование асинхронной обработки (например, `asyncio`).
