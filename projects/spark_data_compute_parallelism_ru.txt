### Задание для студентов по теме: "Реализация приложения на Apache Spark для распределенного обучения модели машинного обучения"

#### Цель:
Создать приложение на основе Apache Spark, которое эффективно использует параллелизм по данным и вычислениям для подготовки данных и распределенного обучения модели машинного обучения.

---

### Требования к приложению:

1. **Подготовка данных с использованием параллелизма по данным:**
   - Прочитать данные из заданного источника (например, HDFS, Kafka или S3).
   - Выполнить обработку данных (например, очистка, агрегация, преобразование) с использованием параллельных операций.

2. **Распределенное обучение моделей:**
   - Использовать OpenMPI или его аналог для организации процесса распределенного обучения нескольких инстансов модели.
   - Реализовать параллелизм как по данным, так и по вычислениям для ускорения обучения.

3. **Управление ресурсами:**
   - Часть, отвечающая за обработку данных, должна уметь динамически запрашивать и освобождать ресурсы (executors) для оптимизации работы.
   - Часть обучения должна быть настроена на использование другого профиля ресурсов для более интенсивных вычислений.

4. **Репартицирование и coalescing:**
   - Обеспечить правильное разбиение данных между процессами для минимизации лишних shuffle-операций.
   - Использовать bucketing для предотвращения избыточных shuffle-операций.

5. **Гиперпараметрический поиск:**
   - Реализовать обучение нескольких инстансов модели параллельно для подбора оптимальных гиперпараметров.

6. **Тестирование производительности:**
   - Провести тестирование приложения на наборе данных, включающем как минимум 1 миллион записей.
   - Провести измерение времени подготовки данных и времени обучения модели.

---

### Инструкции по выполнению:

1. **Подготовка инфраструктуры:**
   - Разверните кластер Apache Spark в Kubernetes (можно использовать Minikube для локального тестирования).
   - Настройте OpenMPI для работы с распределенными процессами.

2. **Реализация обработки данных:**
   - Напишите Spark-скрипт для чтения, обработки и подготовки данных.
   - Настройте репартицирование данных и минимизацию shuffle-операций.

3. **Реализация распределенного обучения:**
   - Реализуйте обучение модели с использованием SparkML или PySpark в сочетании с OpenMPI.
   - Обеспечьте параллельное выполнение нескольких инстансов модели для гиперпараметрического поиска.

4. **Деплой и тестирование:**
   - Разверните приложение на кластере Kubernetes.
   - Проведите тестирование на производительность и оцените, как изменяется время выполнения при увеличении объема данных или числа гиперпараметров.

5. **Отчетность:**
   - Предоставьте отчёт с описанием архитектуры решения, скриншотами графиков нагрузки на Spark Executors, а также результатами обучения модели.

---

### Критерии оценки:

1. **Функциональность (50%):**
   - Корректность обработки данных и распределенного обучения.
   - Правильная реализация параллелизма.

2. **Производительность (20%):**
   - Успешное выполнение на большом объёме данных с минимальным временем.

3. **Качество кода (10%):**
   - Понятность и читаемость кода.
   - Наличие комментариев.

4. **Использование ресурсов (10%):**
   - Эффективное использование ресурсов кластера (минимизация избыточных shuffle и правильная настройка bucketing).

5. **Документация (10%):**
   - Описание архитектуры решения и предоставленные скриншоты/результаты.

---

### Формат сдачи:
- Репозиторий с кодом и инструкциями для развертывания.
- Архив с логами и результатами тестирования.
- Отчет в формате PDF.
