## 2. Uploading Data to ClickHouse Cluster

In order to upload the data to the ClickHouse cluster, I did the following:

- Created a source table from the MergeTree family.

CREATE TABLE aal_372475.transactions ON CLUSTER kube_clickhouse_cluster
(
    `user_id_out` Int64,
    `user_id_in` Int64,
    `important` Int8,
    `amount` Float64,
    `datetime` DateTime
)
ENGINE = MergeTree
PARTITION BY toYYYYMM(datetime)
ORDER BY user_id_out;

- Created a distributed table, choosing the sharded expression for `user_id_out` because both `user_id_out` and `user_id_in` define the same ids.

CREATE TABLE aal_372475.transactions_distributed ON CLUSTER kube_clickhouse_cluster AS aal_372475.transactions
ENGINE = Distributed(kube_clickhouse_cluster, aal_372475, transactions, xxHash64(user_id_out));

- Uploaded the data using the following command (after creating ALL tables and MVs, because they work only on new data).

cat shared-data/clickhouse_data/transactions_12M.parquet | \
clickhouse-client --host=clickhouse-1.clickhouse.clickh \
--user=aal_372475 \
--ask-password \
--query="INSERT INTO aal_372475.transactions_distributed FORMAT Parquet"

## 3. Adjustments and Additional Tables

In the previous submission, I used an inner join, which was NOT correct. Therefore, I made the following adjustments:

- An additional table for the aggregation of user transactions (in, out per month).


- 2 additional MVs (in, out), in order to aggregate (sum) the incoming amount and the outgoing amount for each user ID. This will help in creating the 3rd and 4th MVs in a direct and correct way.


### Additional Table for Aggregation

- The aggregation of user transactions (in, out per month) will be filled with data from the `AggregateFunction` and the `sumState` in the helper MVs.

CREATE TABLE aal_372475.transactions_aggregated ON CLUSTER kube_clickhouse_cluster
(
    user_id Int64,
    income_amount AggregateFunction(sum, Float64),
    outcome_amount AggregateFunction(sum, Float64),
    month DateTime
)
ENGINE = AggregatingMergeTree
ORDER BY (user_id, month);

CREATE TABLE aal_372475.transactions_aggregated_distributed ON CLUSTER kube_clickhouse_cluster AS aal_372475.transactions_aggregated
ENGINE = Distributed(kube_clickhouse_cluster, aal_372475, transactions_aggregated, xxHash64(user_id));

### First Helper MV (Outgoing Total Amount)

- This helper MV contains the outgoing total amount.

CREATE MATERIALIZED VIEW aal_372475.outcome_aggregated ON CLUSTER kube_clickhouse_cluster TO aal_372475.transactions_aggregated_distributed
AS
SELECT
    user_id_out AS user_id,
    sumState(amount) AS outcome_amount,
    toDate(toStartOfMonth(datetime)) AS month
FROM aal_372475.transactions
GROUP BY user_id, month;


CREATE TABLE aal_372475.outcome_aggregated_distributed ON CLUSTER kube_clickhouse_cluster AS aal_372475.outcome_aggregated
ENGINE = Distributed(kube_clickhouse_cluster, aal_372475, outcome_aggregated);


### Second Helper MV (Incoming Total Amount)

- This helper MV contains the incoming total amount.

CREATE MATERIALIZED VIEW aal_372475.income_aggregated ON CLUSTER kube_clickhouse_cluster TO aal_372475.transactions_aggregated_distributed
AS
SELECT
    user_id_in AS user_id,
    sumState(amount) AS income_amount,
    toDate(toStartOfMonth(datetime)) AS month
FROM aal_372475.transactions
GROUP BY user_id, month;


CREATE TABLE aal_372475.income_aggregated_distributed ON CLUSTER kube_clickhouse_cluster AS aal_372475.income_aggregated
ENGINE = Distributed(kube_clickhouse_cluster, aal_372475, income_aggregated);

## 4. Creating the 3rd and 4th MVs

Finally, we can create the 3rd and 4th MVs:

- **3rd MV**: The sums for incoming and outgoing transactions by months for each user.

CREATE MATERIALIZED VIEW aal_372475.sum_tot_month ON CLUSTER kube_clickhouse_cluster
ENGINE = SummingMergeTree
ORDER BY (user_id, month) AS
SELECT
    user_id AS user_id,
    sumMerge(income_amount) AS income_total,
    sumMerge(outcome_amount) AS outcome_total,
    formatDateTime(month, '%m.%Y') AS month
FROM aal_372475.transactions_aggregated
GROUP BY user_id, month;


CREATE TABLE aal_372475.sum_tot_month_distributed ON CLUSTER kube_clickhouse_cluster AS aal_372475.sum_tot_month
ENGINE = Distributed(kube_clickhouse_cluster, aal_372475, sum_tot_month);

SELECT * 
FROM aal_372475.sum_tot_month_distributed 
LIMIT 5;


- **4th MV**: Users' saldo for the current moment.

CREATE MATERIALIZED VIEW aal_372475.users_saldos ON CLUSTER kube_clickhouse_cluster
ENGINE = SummingMergeTree
ORDER BY user_id AS
SELECT
    user_id AS user_id,
    sumMerge(income_amount) - sumMerge(outcome_amount) AS saldo
FROM aal_372475.transactions_aggregated
GROUP BY user_id;

CREATE TABLE aal_372475.users_saldos_distributed ON CLUSTER kube_clickhouse_cluster AS aal_372475.users_saldos
ENGINE = Distributed(kube_clickhouse_cluster, aal_372475, users_saldos);


SELECT * 
FROM aal_372475.users_saldos_distributed 
LIMIT 5;
